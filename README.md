Fitness Club Management System (Java)
A simple Java backend application for managing fitness club members and trainers.
The project demonstrates OOP principles, layered architecture (Controller–Service–Repository), CRUD operations, soft delete, validation, and in‑memory data storage.

Features
Create new members
Soft delete (mark inactive)
Restore deleted members
Get member by ID or name
List all active members
Count active members
Domain models with equals, hashCode, toString
Simple in‑memory repository
Controller–Service architecture

Tech Stack
Java 17
Maven
OOP
Collections API
